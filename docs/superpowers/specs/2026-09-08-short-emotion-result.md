# Short Emotion Result Design

## Goal

감정인식 로봇이 사용자의 첫 답변 뒤에는 한 번 더 공감 질문을 하고, 두 번째 답변부터 감정이 명확하면 결과를 보여주며, 세 번째 답변에는 반드시 결과를 보여준다. 모바일 결과 화면에서는 로봇 이미지를 약 320px 이내로 줄여 감정명, 답변, 저장 상태가 한 화면에 최대한 함께 보이도록 한다.

## Conversation behavior

- 사용자 발화 1회: `complete`를 항상 `false`로 보정하고 공감 표현과 질문 하나를 반환한다.
- 사용자 발화 2회: Gemini가 감정이 명확하다고 판단하면 `complete: true`와 허용된 감정 하나를 반환할 수 있다.
- 사용자 발화 3회 이상: 허용된 감정 하나를 선택하고 `complete`를 항상 `true`로 보정한다.
- 결과 응답에는 후속 질문을 강제하지 않고 짧은 공감 요약을 사용한다.
- 기존 안전 안내와 Google Sheets 저장 흐름은 유지한다.

## Responsive result layout

- 719px 이하에서 결과 카드 이미지는 `min(100%, 320px)` 너비의 정사각형으로 중앙 정렬한다.
- 카드 패딩과 요소 간격을 줄여 이미지와 결과 문구의 시각적 균형을 맞춘다.
- 기존 감정 래스터 자산을 재사용하고 새 이미지는 생성하지 않는다.
- 데스크톱의 2열 결과 구조는 유지한다.

## Verification

- Gemini gateway 단위 테스트로 1회/2회/3회 경계를 검증한다.
- Playwright 모바일 회귀 테스트로 결과 이미지가 320px를 넘지 않는지 검증한다.
- 전체 lint, typecheck, build, unit/integration, E2E 게이트를 통과한 뒤 한 번만 프로덕션 배포한다.
